# FinCredit research workstation

Purpose: make evidence review and counterarguments the primary task, with portfolio changes remaining explicit user actions.

The committee uses restrained TailAdmin-style workspace navigation, a persistent saved-research rail, and a primary tabbed report surface. Existing financial workflows remain reachable. Dark neutral surfaces (#0c121d, #101722), quiet borders (#263142), readable secondary text (#a1afc2), and a single blue action accent (#b6ccff) establish hierarchy. Amber means a limitation, not a market signal. No invented live metrics, accuracy percentages, price charts, or connectivity indicators.

Typography: existing Inter/Geist stack; compact uppercase section labels, 14px research body, tabular numerical tables. Desktop uses history/content columns; narrow screens stack them and provide a complete navigation menu. Controls have visible focus and reduced-motion support. Evidence and interpretations stay separate. Source IDs link to inspected records; advanced view exposes provenance without hiding limitations in guided view.

Source inspiration: TailAdmin dashboard hierarchy and Vercel web-interface guidelines. No proprietary template assets or paid component dependencies were copied. The implementation uses the repository's existing React, Tailwind and Lucide dependencies.
